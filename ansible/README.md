# Ansible

Configures the OS/environment on the EC2 instance Terraform provisions (see
`../terraform/README.md`). `inventory/hosts.ini` is generated by Terraform — don't hand-edit it.

## Roles (run in this order via `site.yml`)

1. **common** — base packages, timezone, app user/group, swapfile, sshd hardening.
2. **c10k_tuning** — sysctl tuning for a high-concurrency epoll TCP/HTTP server.
3. **cpp_toolchain** — `build-base`/`cmake`/`git` for on-box aarch64/musl compilation.
4. **logging** — logrotate + dcron, since the server writes its own log files.
5. **app_service** — `/opt/temperingworks` layout, OpenRC service, syncs a locally-built
   binary and frontend `dist/` if `app_binary_local_path` / `frontend_dist_local_dir`
   (see `group_vars/all.yml`) are set — otherwise it just prepares the service, stopped.

## One-time setup

```
ansible-galaxy collection install -r requirements.yml
```

## One-time sshd_config.orig capture

The `common` role's sshd hardening replaces `/etc/ssh/sshd_config` wholesale. Before
running it against a **fresh** instance for the first time, capture Alpine's shipped
default so it's kept as reference material alongside the template:

```
ansible -m fetch -a "src=/etc/ssh/sshd_config dest=roles/common/files/sshd_config.orig flat=yes" temperingworks_web
```

Commit the resulting file in place of the placeholder, then run the playbook.

## Run

```
ansible-playbook site.yml
```

Set `app_binary_local_path` / `frontend_dist_local_dir` (via `-e` or a host_vars file,
not committed to `group_vars/all.yml`) once a real build exists, and re-run to sync +
start the service. Flip `app_bind_privileged_port: true` and `app_http_port: 80` in
`group_vars/all.yml` when ready to serve on the standard HTTP port.
